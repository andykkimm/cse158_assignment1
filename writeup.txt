TASK 1: READ PREDICTION
================================================================================

Approach:
I implemented a hybrid collaborative filtering approach that combines multiple features
to predict whether a user will read a book:

1. Book Popularity: Calculated the popularity of each book based on the fraction of total
   interactions. Popular books are more likely to be read.

2. Jaccard Similarity: For users we've seen before, I computed the Jaccard similarity
   between the set of users who read the candidate book and the set of users who read
   books that the target user has read. This captures collaborative filtering signals.

3. User Activity Level: Users who have read more books are more likely to read additional
   books. I normalized this by the number of interactions.

4. Popular Book Set: Following the baseline approach, I identified books that account
   for 50% of all interactions and gave them higher weight.

Final Model:
The prediction score is a weighted combination:
  score = 0.4 * is_popular + 0.3 * popularity_score * 100 +
          0.2 * jaccard_similarity + 0.1 * user_activity_score

To ensure exactly 50% of predictions are "read" (as specified in the task), I sorted
all test pairs by their scores and selected the top 50% as positive predictions.

This approach significantly outperforms the baseline by incorporating collaborative
filtering signals beyond simple popularity.

================================================================================
TASK 2: CATEGORY PREDICTION
================================================================================

Approach:
I implemented a text classification approach using TF-IDF features and Logistic Regression:

1. Text Preprocessing: Extracted review text from the training data (100,000 reviews)

2. Feature Extraction: Used TfidfVectorizer with the following parameters:
   - max_features=5000: Limit vocabulary to top 5000 features
   - ngram_range=(1,2): Include both unigrams and bigrams to capture phrases
   - min_df=2: Ignore terms that appear in fewer than 2 documents
   - max_df=0.8: Ignore terms that appear in more than 80% of documents
   - stop_words='english': Remove common English stop words

3. Classification Model: Trained a multinomial Logistic Regression classifier
   - Achieved ~77.7% training accuracy
   - Uses L2 regularization (C=1.0) to prevent overfitting
   - Multinomial setting for multi-class classification

This approach substantially improves over the keyword-matching baseline by learning
which words and phrases are most discriminative for each genre category, capturing
more nuanced patterns in the review text.

================================================================================
TASK 3: RATING PREDICTION
================================================================================

Approach:
I implemented a bias-based collaborative filtering model that accounts for user and
item effects:

1. Global Baseline: Computed the global average rating (3.687) as the base prediction

2. User and Item Biases: Calculated bias terms for each user and book:
   - User bias = user's average rating - global average
   - Item bias = book's average rating - global average

3. Damped Averages: To avoid overfitting on users/books with few ratings, I used
   damped/regularized averages with a damping factor of 10:
   damped_avg = (sum(ratings) + damping * global_avg) / (count + damping)

4. Weighted Prediction Model: For each user-book pair, the prediction combines:
   - User average rating (weighted by user's rating count)
   - Book average rating (weighted by book's rating count)
   - Bias-based prediction (global + 0.5*user_bias + 0.5*item_bias)

5. Fallback Strategy:
   - If both user and book are known: weighted combination based on data availability
   - If only user known: 70% user average + 30% global average
   - If only book known: 70% book average + 30% global average
   - If neither known: global average

6. Range Clipping: All predictions are clipped to the valid range [1, 5]

This model captures both user preferences (some users rate higher/lower on average)
and item quality (some books are rated higher/lower on average), which significantly
improves upon the baseline that only uses user averages.
